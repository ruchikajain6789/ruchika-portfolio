Product Case Study

AI Customer Support Copilot

Overview

The AI Customer Support Copilot is a prototype designed to help customer support agents respond to customer questions using AI. It connects to the Gemini API to generate responses to user queries. The prototype uses a small knowledge base to retrieve relevant information, displays supporting sources and a confidence indicator, and allows agents to review or edit AI-generated responses before using them.
